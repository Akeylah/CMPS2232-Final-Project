========================================
PHASE 1: USER AUTHENTICATION
========================================

1. User opens app

2. User selects:
   → Sign Up
   OR
   → Log In

------------------------- 
SIGN UP FLOW
-------------------------
Frontend:
POST /api/auth/signup

Backend:
- Validate username uniqueness
- Hash password

DB:
INSERT INTO Users (username, password, role)
VALUES (?, ?, 'customer')

- Create empty cart

INSERT INTO Cart (user_id)

Response:
→ User created successfully


-------------------------
LOGIN FLOW
-------------------------
Frontend:
POST /api/auth/login

Backend:
- Verify username + password

DB:
SELECT * FROM Users WHERE username = ?

Response:
→ Return user_id + role
→ Redirect to Menu Page


========================================
PHASE 2: MENU BROWSING
========================================

Frontend:
GET /api/menu-items

Backend:
DB:
SELECT * FROM MenuItems

Response:
→ List of food items displayed


========================================
PHASE 3: ADD TO CART
========================================

Frontend:
POST /api/cart/add

Payload:
{
  user_id,
  item_id,
  quantity
}

Backend:
1. Get user's cart

DB:
SELECT cart_id FROM Cart WHERE user_id = ?

2. Check if item already exists

IF EXISTS:
  UPDATE CartItems
  SET quantity = quantity + ?
  WHERE cart_id = ? AND item_id = ?

ELSE:
  INSERT INTO CartItems (cart_id, item_id, quantity)

Response:
→ Cart updated


========================================
PHASE 4: VIEW CART
========================================

Frontend:
GET /api/cart

Backend:
DB:
SELECT 
  ci.cart_item_id,
  m.name,
  m.price,
  ci.quantity
FROM CartItems ci
JOIN MenuItems m ON ci.item_id = m.item_id
WHERE ci.cart_id = ?

Response:
→ Display cart items + total price


========================================
PHASE 5: CHECKOUT
========================================

Frontend:
POST /api/orders/create

Payload:
{
  user_id,
  order_type (pickup/delivery)
}

Backend:

1. Get cart items

DB:
SELECT * FROM CartItems WHERE cart_id = ?

2. Calculate total price

3. Create Order

INSERT INTO Orders (user_id, order_type, status, total_price)
VALUES (?, ?, 'pending', ?)

4. Save order items

FOR EACH cart item:
INSERT INTO OrderItems (order_id, item_id, quantity, price)

5. IF delivery:

INSERT INTO DeliveryDetails (order_id, address, delivery_fee)

6. Create payment record

INSERT INTO Payments (order_id, method, payment_status)
VALUES (?, ?, 'pending')

7. Clear cart

DELETE FROM CartItems WHERE cart_id = ?

Response:
→ Order placed successfully
→ Return order_id


========================================
PHASE 6: PAYMENT
========================================

Frontend:
POST /api/payment/pay

Payload:
{
  order_id,
  method (pickup_payment / cash_on_delivery)
}

Backend:

UPDATE Payments
SET payment_status = 'paid'
WHERE order_id = ?

Response:
→ Payment confirmed


========================================
PHASE 7: ORDER TRACKING (USER SIDE)
========================================

Frontend:
GET /api/orders/{order_id}

Backend:
DB:
SELECT * FROM Orders WHERE order_id = ?

Response:
→ status User:
   - pending
   - completed
   
→ status Admin:

   - edit  (btn)
   - cancel (btn)
   - completed (btn)


========================================
PHASE 8: ADMIN ORDER MANAGEMENT
========================================

(Admin Dashboard)

Frontend:
GET /api/admin/orders

Backend:
DB:
SELECT * FROM Orders ORDER BY created_at DESC

--------------------------------
UPDATE ORDER STATUS
--------------------------------

Frontend:
PUT /api/admin/orders/{order_id}

Payload:
{
  status
}

Backend:
UPDATE Orders
SET status = ?
WHERE order_id = ?

--------------------------------
STATUS FLOW
--------------------------------

pending → preparing → ready → completed
                 ↘
                 cancelled


========================================
PHASE 9: ORDER COMPLETION
========================================

WHEN:
Orders.status = 'completed'
AND Payments.payment_status = 'paid'

System:
→ Order is officially finished

Optional:
→ Send confirmation notification
→ Store for order history


========================================
BONUS: ORDER HISTORY
========================================

Frontend:
GET /api/orders/user/{user_id}

Backend:
DB:
SELECT * FROM Orders WHERE user_id = ?

Response:
→ List of past orders
